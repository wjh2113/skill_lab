# 翻译 Prompt（固定）

将以下英文 Markdown 博客全文翻译为简体中文。严格遵守以下规则：

## 规则

1. **保留 Markdown 结构**：标题层级（`#`–`######`）、列表、引用块、表格、链接语法、图片语法均保持不变
2. **代码块不翻译**： fenced code blocks（\`\`\`）和行内代码（\`）内的内容保持原样
3. **链接**：链接 URL 保持不变；链接文字翻译为中文
4. **专有名词**：产品名、库名、协议名等保留英文；首次出现时在括号内给出中文说明（可选）
5. **语气**：技术博客风格，准确、清晰，避免过度口语化
6. **不要添加内容**：不添加译者注、不删减段落、不重组章节

## 输出

直接输出完整的中文 Markdown，不要包裹在代码块中，不要添加「译文如下」等前缀。
